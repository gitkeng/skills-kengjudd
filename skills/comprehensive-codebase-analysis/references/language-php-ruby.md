# PHP and Ruby playbook

## PHP

Inspect Composer metadata/locks, autoloading, framework routes/controllers/middleware, templates, commands, workers, migrations, and tests. Record methods, types, attributes/annotations, magic methods, global state, configuration keys, and runtime extensions. Check loose comparison, unsafe inclusion, upload/path handling, query/command construction, output encoding, session authorization, request-forgery controls, deserialization, and error-display settings.

## Ruby

Inspect Gem metadata/locks, application/config files, routes, controllers, models, jobs, tasks, initializers, migrations, metaprogramming, and tests. Record method contracts, modules/mixins, callbacks, dynamically generated APIs, configuration credentials, and environment variables. Check mass assignment, authorization filters, request-forgery controls, query/string evaluation, unsafe YAML/object loading, command execution, secret handling, callback side effects, and broad rescue.

For both, explain confidence reductions from dynamic dispatch, monkey patching, runtime registration, and convention-only framework behavior. Count explicit branch/loop/rescue decisions with documented heuristic rules.
