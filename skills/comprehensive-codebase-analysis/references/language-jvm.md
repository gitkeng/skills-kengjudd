# Java and Kotlin playbook

Inspect Maven/Gradle settings, modules, dependency scopes, plugins, toolchains, runtime targets, framework configuration, annotations, service loaders, resources, and test source sets.

Trace entry points through application/bootstrap classes, servlet or reactive routes, consumers, schedulers, and command handlers. Record full interface signatures, visibility, checked exceptions, generics, nullability annotations, coroutine/suspend boundaries, and reflection-driven contracts.

Map persistence annotations, repositories, transactions, lazy loading, migrations, and generated queries. Check authorization annotations/interceptors, request-forgery protections for cookie-backed state changes, binding/validation, deserialization, expression/query construction, secrets, and exception translation.

Estimate complexity per method from branch decisions; treat Kotlin expression branches, safe-call control paths, and coroutine state carefully and label estimates. Separate production, generated, and test code. Note runtime/dependency versions only from build evidence; use registry and lifecycle pointers for later verification.
