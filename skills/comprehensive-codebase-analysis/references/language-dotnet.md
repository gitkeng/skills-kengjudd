# C# and .NET playbook

Inspect solution/project files, target frameworks, package manifests, build properties, configuration transforms, startup/hosting files, middleware, routes, filters, controllers, background services, and test projects.

Record full signatures including accessibility, generic constraints, attributes, nullable annotations, async return types, events, delegates, and extension methods. Treat configuration keys, named connections, options binding, environment variables, and dependency-injection registrations as interfaces.

Map ORM contexts, entities, migrations, relationships, lazy/eager loading, transaction boundaries, raw queries, and inferred database constraints. For web endpoints build authentication, authorization, role/policy, request-forgery, binding, and verb matrices. Distinguish authentication-only filters from authorization.

Count complexity from decisions in methods, pattern guards, loops, catches, conditional operators, and short-circuit branches; label the result estimated. Check nullability around query methods, disposal, sync-over-async, broad catches, output encoding, redirect validation, password derivation, session handling, and logging sinks.
