# Python playbook

Inspect project metadata, requirement/lock files, packages, namespace packages, entry points, framework settings, routes, commands, workers, tasks, migrations, and tests. Separate runtime, development, and optional dependencies.

Record callable signatures including decorators, positional-only and keyword-only parameters, defaults, type hints, async/generator behavior, protocols, and dynamically registered interfaces. Treat settings keys and environment access as implicit contracts.

Trace ORM models, transactions, query construction, serializers, templates, and background queues. Check authorization decorators/dependencies, request-forgery controls for session-backed web actions, unsafe evaluation, subprocess use, deserialization, path handling, secret defaults, exception breadth, and logging.

Count decisions from `if`, loops, catches, boolean branches, comprehensions with filters, and match guards; state the chosen counting convention and label estimates. Dynamic dispatch, monkey patching, metaclasses, and import-time registration lower confidence and require explicit inference evidence.
