# C and C++ playbook

Inspect native build files, compiler standards/flags, targets, include paths, preprocessor definitions, package metadata, platform branches, entry points, exported headers, ABI boundaries, generated sources, and tests.

Record function, method, template, callback, macro-facing, and foreign-function signatures. Document ownership, lifetimes, allocation/deallocation pairs, exceptions/error codes, thread synchronization, configuration inputs, and compile-time contracts.

Map include and link dependencies separately. Check bounds, integer conversion/overflow, format strings, use-after-free, double-free, null dereference, uninitialized state, unsafe C APIs, race/deadlock risks, command/path handling, parsing limits, and error cleanup.

Count explicit decisions plus conditional compilation paths using a declared convention; template and macro expansion makes results estimates. Distinguish C from C++ semantics and note compiler/platform dialects. Treat third-party headers and generated bindings as inventoried but not first-party findings unless integration is defective.
